# ShiftSure rider app

Flutter app for Android and iOS. **Status:** scaffold implemented (PR #6); email/password sign-in **in progress** (PR #7). Setup and run instructions are in the
[root README](../README.md#rider-app-scaffold-implemented-pr-6-sign-in-in-progress-pr-7).

- `lib/api/`: `ApiClient` and `ApiException`
- `lib/auth/`: `AuthService` interface, `FirebaseAuthService`, `initFirebase` (emulator wiring), `AuthGate`
- `lib/config/`: build-time configuration (`API_BASE_URL`, `USE_AUTH_EMULATOR`, `AUTH_EMULATOR_HOST`, `AUTH_EMULATOR_PORT`)
- `lib/navigation/`, `lib/screens/`, `lib/widgets/`: shell, login/registration and placeholder screens
- `lib/theme/`: Material 3 themes
- `lib/firebase_options.dart` and `firebase.json`: generated by FlutterFire, tracked (public dev-project client config); `android/app/google-services.json` is git-ignored
- `test/`: hermetic tests (fake `AuthService` in `test/support/`); no Firebase or emulator needed
- Application ID / bundle ID: `com.shiftsure.rider`
