# ShiftSure rider app (scaffold)

Flutter app for Android and iOS. **Status: scaffold only (PR #6).** Setup, run
instructions and the backend URL table are in the
[root README](../README.md#rider-app-scaffold-in-progress-pr-6).

- `lib/api/`: `ApiClient` and `ApiException`
- `lib/config/`: build-time configuration (`API_BASE_URL`)
- `lib/navigation/`, `lib/screens/`, `lib/widgets/`: shell and placeholder screens
- `lib/theme/`: Material 3 themes
- Application ID / bundle ID: `com.shiftsure.rider`
